# 🏥 WardMate: Intelligent Hospital OS



> "Don't just manage your ward. Orchestrate it."

**WardMate** is a modern, lightweight Hospital Management System designed to replace chaotic paper trails with a centralized, intelligent digital command center. Built with pure Vanilla JS and CSS for maximum performance and zero dependencies.

## 🚀 Key Features

### 1. Real-Time Command Centre
- **Live Census**: monitor bed occupancy across 5 wards (General, Maternity, ICU, Surgical, Pediatrics) instantly.
- **Critical Alerts**: Visual indicators for fluctuating patient vitals or high-acuity cases.

### 2. Intelligent HR & Staffing (AI Powered)
- **Fatigue Watch**: Automatically flags staff exceeding 48-hour work weeks to prevent burnout.
- **Leave Compliance**: Tracks mandatory leave and alerts managers when staff are overdue.
- **Student Rotation**: Suggests optimal mentorship pairings based on student engagement (e.g., pairing Intern George O. with Dr. Bailey).

### 3. Smart Admission Protocols
- **Safety First**: Prevents demographic errors at the door.
  - *Maternity Ward* logic strictly enforces female-only admissions.
  - *Pediatrics Ward* logic blocks admission of patients over 18.
- **Bed Management**: Auto-assigns the next available bed and updates global census.

### 4. Logistics & Supply Chain
- **Central Store**: Monitor stock levels in real-time.
- **One-Click Restock**: Instant restocking requests directly from the dashboard.
- **Predictive Alerts**: "Low Stock" warnings before you run dry.

### 5. AI Chat Assistant
- **Natural Language Interface**: Ask questions like "Who needs leave?" or "Is the ward full?"
- **Instant Insights**: Get data-driven recommendations without digging through reports.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Custom Utility-First Design System).
- **Logic**: Vanilla JavaScript (ES6+).
- **Backend/Data**: In-Memory State & Mock Data (Demo Mode).
- **Zero Dependencies**: No React, No Tailwind, No Build Steps. Just pure code.
